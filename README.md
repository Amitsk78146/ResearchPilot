# ResearchPilot

An Agentic AI Research Assistant.

## Project Objective

ResearchPilot is designed to assist scientific
researchers with:

- Research paper analysis
- Literature comparison
- Scientific data analysis
- Evidence-backed research reports
- Agentic AI workflows

## Technology Stack

- Python
- LangGraph
- Streamlit
- ChromaDB
- Pandas
- NumPy
- Pydantic
